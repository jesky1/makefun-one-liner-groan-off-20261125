One original dad joke, one line, written by a small deterministic Node program for make.fun's "The One-Liner Groan-Off" bounty ($2 in USDC, top 10). The line: Dad calls his naps "system updates" — he lies down, makes a weird noise, and wakes up insisting nothing changed.

## Run it

```sh
node main.ts
```

It validates the line (1–140 characters, one line, no trailing whitespace, no control or invisible characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Tests

```sh
node --test test.mjs test-neg.mjs
```
